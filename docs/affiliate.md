# Affiliate Engine

Cada oferta pode possuir um link afiliado separado:

```text
Offer
  -> AffiliateProgram
  -> AffiliateLink
  -> Click
  -> Conversion
```

Métricas:
- cliques
- conversões
- GMV
- comissão
- EPC
- conversão por canal
- conversão por produto

Links afiliados devem ser identificados de forma transparente ao usuário.
