# Price Engine

O preço de referência deve considerar:

- mediana
- média
- mínimo confiável
- condição
- idioma
- variante
- frete
- histórico
- fonte

Exemplo:

```text
Preço anunciado: R$ 320
Frete: R$ 20
Preço efetivo: R$ 340
Referência: R$ 415
Diferença: -18,07%
```

Nunca tratar automaticamente o menor preço isolado como preço de mercado.
